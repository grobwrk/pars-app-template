Template application that uses the **pars** C++23 framework.

Follow the [tutorial](https://grobx.github.io/pars-cxx/v0.2.0/sphinx/tutorial/index.html#create-an-application-from-scratch) to create an application using this template.

This application template implement the same `client` that you can find in the `examples` folder of [pars-cxx](https://github.com/grobx/pars-cxx).
