Template application that uses the **pars** C++23 framework.

Follow the [tutorial](https://grobwrk.github.io/pars/v0.1.2/sphinx/tutorial/index.html#create-an-application-from-scratch) to create an application using this template.

This application template implement the same `client` that you can find in the `examples` folder of [pars](https://github.com/grobwrk/pars).
